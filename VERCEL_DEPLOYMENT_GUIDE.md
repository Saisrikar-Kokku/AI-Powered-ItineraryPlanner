# Vercel Deployment Guide - Indian Market

This guide will help you deploy your AI-Powered Itinerary Planner to Vercel with proper environment variable configuration.

## 🚀 **Step-by-Step Vercel Deployment**

### **Method 1: Using Vercel Dashboard (Recommended)**

#### **Step 1: Connect Your Repository**
1. Go to [vercel.com](https://vercel.com) and sign in
2. Click **"New Project"**
3. Import your GitHub repository
4. Select your **AI-PoweredIteneryPlanner** repository

#### **Step 2: Configure Environment Variables**
In the **Environment Variables** section, add these variables:

```env
# Supabase Configuration
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key-here

# Gemini AI API Key
NEXT_PUBLIC_GEMINI_API_KEY=your-gemini-api-key-here

# App URL (will be auto-generated)
NEXT_PUBLIC_APP_URL=https://your-app-name.vercel.app
```

#### **Step 3: Add Each Variable**
1. Click **"Add Environment Variable"**
2. **Name**: `NEXT_PUBLIC_SUPABASE_URL`
3. **Value**: Your Supabase project URL
4. **Environment**: Select **Production**, **Preview**, and **Development**
5. Click **"Save"**

Repeat for each variable:
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `NEXT_PUBLIC_GEMINI_API_KEY`
- `NEXT_PUBLIC_APP_URL`

#### **Step 4: Deploy**
1. Click **"Deploy"**
2. Wait for deployment to complete
3. Your app will be live at `https://your-app-name.vercel.app`

## 🔧 **Environment Variable Setup**

### **Where to Get Your Values**

#### **1. Supabase Configuration**
1. Go to your [Supabase Dashboard](https://supabase.com/dashboard)
2. Select your project
3. Go to **Settings** → **API**
4. Copy:
   - **Project URL**: `https://your-project-id.supabase.co`
   - **anon public key**: The long string starting with `eyJ...`

#### **2. Gemini API Key**
1. Go to [Google AI Studio](https://aistudio.google.com/)
2. Click **"Get API Key"**
3. Create a new API key
4. Copy the generated key

#### **3. App URL**
- This will be automatically generated by Vercel
- Format: `https://your-app-name.vercel.app`

## ⚠️ **Common Issues & Solutions**

### **Issue 1: "Secret does not exist" Error**
**Problem**: The error you encountered with `@supabase-url` references.

**Solution**: 
- ✅ **Fixed**: Removed the `env` section from `vercel.json`
- ✅ **Use**: Vercel Dashboard to add environment variables directly
- ✅ **Don't use**: `@secret-name` syntax unless you've created secrets first

### **Issue 2: Environment Variables Not Loading**
**Solution**:
1. Ensure variable names start with `NEXT_PUBLIC_` for client-side access
2. Redeploy after adding environment variables
3. Check that variables are set for **Production** environment

### **Issue 3: Build Failures**
**Solution**:
1. Check that all required environment variables are set
2. Ensure API keys are valid and active
3. Verify Supabase project is properly configured

## 🔐 **Security Best Practices**

### **Environment Variables**
- ✅ **Use Vercel Dashboard** for environment variables
- ✅ **Never commit** `.env.local` to git
- ✅ **Use different keys** for development and production
- ✅ **Rotate API keys** regularly

### **Supabase Security**
- ✅ **Enable RLS** (Row Level Security)
- ✅ **Set up proper policies** for user data
- ✅ **Use anon key** for client-side operations
- ✅ **Monitor usage** in Supabase dashboard
